# IoT Smart Door (ESP8266 + SIM800L)

![C++](https://img.shields.io/badge/C%2B%2B-00599C?logo=cplusplus&logoColor=white) ![Arduino](https://img.shields.io/badge/Arduino-00878F?logo=arduino&logoColor=white) ![License: MIT](https://img.shields.io/badge/License-MIT-green.svg)

A smart access-control door built on an **ESP8266** Wi-Fi module and a **SIM800L** GSM module (Embedded Systems / IoT project, B.Sc. in Computer Engineering).

- Opens over **Wi-Fi**: the ESP8266 creates its own Wi-Fi access point for control.
- Opens over **SMS**: the SIM800L receives and checks commands with AT commands.

## How to use

Open `Code.cpp` in the Arduino IDE with the ESP8266 board package installed, set `SSID` and `PASSWORD`, and upload.
